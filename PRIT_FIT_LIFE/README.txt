PRIT - FIT LIFE
================

Projeto acadêmico convertido do layout do Figma para HTML, CSS e JavaScript.

Como abrir:
1. Extraia a pasta.
2. Abra a pasta no VS Code.
3. Abra o arquivo index.html.
4. Para uma experiência melhor, use a extensão Live Server do VS Code e clique em "Open with Live Server".

Arquivos principais:
- index.html = página inicial
- produtos.html = catálogo
- login.html = login
- criar-conta.html = cadastro
- carrinho.html = carrinho funcional com localStorage
- exercicios*.html = páginas de exercícios
- page-fem.html / page-masculina.html / page-unisex.html = roupas
- acessorios.html = acessórios
- whey.html / energia.html / saude.html / emagrecimento.html = categorias
- css/style.css = visual
- js/app.js = produtos, carrinho e interações

Observação:
As imagens dos produtos foram representadas por mockups CSS para o projeto funcionar sem depender de imagens externas. Se você tiver os PNGs/JPGs do Figma, eles podem ser colocados em uma pasta img e ligados nos cards.
